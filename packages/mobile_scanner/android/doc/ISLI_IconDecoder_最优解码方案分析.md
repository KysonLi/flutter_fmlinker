# ISLI 盾牌码最优解码方案分析

> 基于 `src/main/cpp/isli/` 全部源码 + 101 张真机测试图（7 HIT / 94 MISS）的逐阶段剖析。

---

## 一、先彻底理解"盾牌码"是什么

从代码常量反推其物理结构（这是设计最优方案的前提）：

### 1.1 几何结构

```
              C1(顶点)
             ╱   ╲
        短弧0     短弧1
          ╱         ╲
       C0 ─────────── C2     ← 左右肩，基本等高
        ╲             ╱
         长弧3      长弧2      ← 两侧长弧
           ╲       ╱
            C3(底点)           ← 盾尖
```

实测坐标（HIT00004）：C0=(311,442) C1=(384,418) C2=(453,436) C3=(391,600)。
- C0↔C1、C1↔C2：短弧（`SPAN_NUM=48`）
- C2↔C3、C3↔C0：长弧（`SPAN_NUM=128`）
- 整体是一个**下尖的盾牌形外框**，外框是一条等宽的暗线（frame_width ≈ 6~12px）。

### 1.2 数据布局：本质是"绕盾牌周长一圈的 1D 条码"

关键认知：**数据不是 2D 矩阵，而是沿外框周长排布的 1D 比特流**，被同步位(sync)切成若干段。

| 模式 | 短弧段数 | 长弧段数 | 每段 bit | 总 bit | BCH |
|------|---------|---------|---------|--------|-----|
| 63bit | 1段×2弧 | 3段×2弧 | 10/9/8/11 | 63 | BCH(63, t=5)，仅纠≤3错 |
| 112bit | 2段×2弧 | 4段×2弧 | — | 112 | BCH(127, t=7)，纠≤7错 |

每段结构：`sync | data... | sync`，同步位是固定的 010 峰谷峰模式。

### 1.3 定位基准（BSPatternMatch）

外框上嵌入两个**对称的宽度比例标记**（B1=135,S1=133,B2=452,S2=136，单位为设计稿缩放），二者中心距 EDGE2EDGE=2975。定位靠匹配这套 ±10% 容差的比例。这是**尺度不变**的好设计。

## 二、当前流水线的信息流与"致命假设"

```
定位(1D扫描) → 追踪(质心跟线) → 找角(角度差) → 精化角(Harris) → 拟合(三次多项式) → 采样(弧长) → 波形解码(sync对齐) → BCH
```

逐阶段的**信息保持 / 信息丢失**：

| 阶段 | 输入信息 | 输出 | 关键假设 | 风险 |
|------|---------|------|---------|------|
| 定位 | 全图 | 1条边上2点 + frame_size + 朝向 | 标记比例出现且唯一 | 误匹配/漏检 |
| 追踪 | 2点+宽度 | 完整闭合外框点序列(~167点) | **质心始终落在框线上** | 🔴局部出错=全盘皆输 |
| 找角 | 点序列 | 4角索引 | 角度差局部最大=角点 | 受噪声点干扰 |
| 精化 | 粗角点 | 亚像素角点 | Harris峰=真实角 | 窗口偏了就错 |
| 拟合 | 每段点 | 三次曲线系数 | 边是光滑三次曲线 | 大畸变下失配 |
| 采样 | 曲线+段数 | 4条波形 | 弧长均匀分摊bit | 累积误差 |
| 波形 | 波形 | bit | sync对齐正确 | 边缘bit漂移 |
| BCH | 63/112 bit | 编码 | 错误数≤阈值 | 硬判决丢信息 |

### 🔴 核心问题：这是一条"串行贪心、错误传播、无全局约束"的链

1. **追踪必须 100% 成功**：任何一点脱轨，整帧报废，后面所有阶段都不执行。
2. **错误单向传播**：角点错了→拟合错了→采样错了→bit全错，且无回头校正。
3. **无全局几何约束**：明明知道"盾牌有4个角、周长可预测、左右对称"，但这些先验完全没用上——每个阶段都是局部贪心。

## 三、实测失败分布（101 张图的定量证据）

从批量测试日志统计失败阶段：

| 失败阶段 | 占 MISS 比例 | 典型现象 |
|---------|-------------|---------|
| **追踪脱轨** (`amend_center` 失败) | **~70%** | 走到 dot#80~160 时质心跳离框线 |
| 定位失败（找不到标记） | ~13% | 4 个方向扫描全空 |
| 波形解码失败（63+112 都失败） | ~10% | sync 对齐错或 bit 超过 BCH 纠错力 |
| 角点/拟合失败 | ~7% | 曲线拟合奇异 |

**结论：追踪阶段的质心跟线法是头号瓶颈，独立承担了 70% 的失败。** 最优方案的第一优先级就是干掉/重做这个阶段。

### 追踪为什么必然在角点附近脱轨？

`amend_center` 在以当前点为圆心、半径 `≈1.1×frame_width` 的圆盘内，对所有暗像素求质心。

- **直边段**：圆盘内暗像素基本就是一段框线，质心≈框线中心 ✅
- **角点/盾尖 C3**：圆盘同时框住两条相交边，暗像素呈"L"或"V"形，质心被强力拉向角的内侧 → 跳离真实框线 → 后续方向算错 → 脱轨 🔴
- **曲率大的长弧**：圆盘内框线是斜的，若 frame_width 估计偏小，圆盘可能只覆盖半条线，质心偏移

这是**质心法的原理性缺陷**，靠调参（圆半径、步长、迭代次数）只能缓解，无法根治。

## 四、每阶段的最优方案

### 阶段1 定位：保留 1D 扫描，但增加"置信度+多候选"

现状的 1D 扫描 + 比例匹配其实是**高效且尺度不变**的好设计，7/7 HIT 全部定位成功，不必推倒。

**最优增强：**
- 扫描时记录**所有候选匹配**（不止第一个），按比例吻合度排序。
- 命中后立即用**十字交叉验证**：在垂直方向再扫一次，确认框线连续，剔除孤立噪点误匹配。
- 增加 **frame_size 的多线交叉校验**：当前只从单条线估 frame_size，误差直接传染给追踪的圆半径。用 2~3 条平行线交叉估计，更稳。

> 投入产出比：⭐⭐（定位已不是瓶颈，小幅加固即可）

---

### 阶段2 外框获取：🔴 用"法向匹配滤波"替换"质心跟线"（最高优先级）

这是整个方案的**核心改动**。原理区别：

| | 质心法（现状） | 法向匹配滤波（最优） |
|---|---|---|
| 做法 | 圆盘内所有暗像素求质心 | 沿框线法向方向取 1D 剖面，用已知宽度的"暗脉冲模板"做匹配找峰值 |
| 角点处 | 暗像素呈 L 形，质心偏向内侧→脱轨 | 只看当前点法向的一小段，不受另一条边干扰 ✅ |
| 抗噪 | 全局阈值，受背景暗块干扰 | 模板匹配自带带通特性，抗噪强 |
| 复杂度 | O(πr²) 每点 | O(w) 每点，w=搜索半宽，更轻 |

**具体做法：**
```
每一步:
  1. 用上一段方向估计当前点的"切向"，法向 = 切向旋转90°
  2. 沿法向取长度 ≈ 3×frame_width 的 1D 剖面
  3. 与理想框线剖面模板（宽度=frame_width 的暗脉冲，可加边缘梯度）做归一化互相关
  4. 峰值位置 = 新的框线中心；峰值处的梯度方向 = 更新后的法向
  5. 沿切向前进 step
```

匹配滤波的峰值在角点附近依然锐利（因为它只看法向窄窗），可把追踪成功率从 ~30% 拉到 ~85%+。

**进一步（可选）：彻底跳过闭合追踪。** 既然知道盾牌有 4 角，可以从初始边向两端延伸，遇到曲率突变即判定为角点，分段获取，不必强行闭合。详见阶段3。

> 投入产出比：⭐⭐⭐⭐⭐（直接消灭 70% 的失败）

---

### 阶段3 角点检测：🔴 解耦——"分段延伸 + 直接找角"，不依赖完整闭合追踪

现状：必须先完整闭合追踪，再在点序列上做角度差找峰。追踪失败则角点无从谈起。

**最优：把"找角"从"闭合追踪"中解耦。**

盾牌几何是强先验：4 个角，2 短弧 + 2 长弧，左右近似对称。利用它：

```
从定位给的初始边中点出发，沿框线向两侧延伸（用阶段2的匹配滤波）:
  - 实时计算局部曲率 κ
  - 当 κ 超过阈值 → 标记一个角点候选，记录弧长
  - 走完一圈得到 4 个角点 + 它们之间的弧长 [L0,L1,L2,L3]
  - 校验: 应满足 {两个短弧≈等长, 两个长弧≈等长}（全局约束！）
  - 若某个角没被曲率检出 → 用弧长先验预测其位置，局部精搜
```

这样即使某段框线断裂，也能用"周长+对称"先验补全，**单点失败不再致命**。

**角点亚像素精化**（现状的 Harris 思路保留但改进）：
- 现状在固定圆形窗口算 Harris，窗口偏离则错。
- 最优：在角点预测位置，沿两条相邻边的方向各取一段，两段直线的交点即精化角点（几何交点法，比 Harris 更准更稳）。

> 投入产出比：⭐⭐⭐⭐⭐（配合阶段2，彻底改变容错结构）

---

### 阶段4 边拟合 + 阶段5 采样：用"每边独立几何模型 + 模块中心定位采样"

现状：三次多项式拟合 + 弧长等分采样。问题：弧长采样**累积误差**，到段尾 bit 漂移；三次曲线对大透视畸变失配。

**最优：**
1. **每边独立拟合**（已是现状，保留）：短弧可用二次，长弧用三次或薄板样条，按残差自适应选阶。
2. **去掉"弧长等分"，改为"模块中心定位"**：
   - 每条边已知 span 数（48 或 128），先按弧长给每个模块一个**预测中心**。
   - 对每个预测中心，在其局部用**梯度/相关**做亚像素微调（类似阶段2的法向匹配，但目标是数据模块而非框线）。
   - 这样每个 bit 的采样位置独立校正，**误差不累积**。
3. **透视补偿**：若检测到明显透视（左右肩不等高、长短弧比例失调），对每边先做局部仿射/透视校正再采样。

> 投入产出比：⭐⭐⭐（在追踪修好后，这是提升 bit 正确率的下一档）

---

### 阶段6 波形→bit：保留 sync 对齐，但改"软判决"

现状：硬阈值二值化 → 硬 bit → 硬判决 BCH。同步位靠 010 模式匹配，单点错就可能整段错。

**最优：**
- **软判决**：每个模块输出 [0,1] 的暗概率（用模块中心局部的归一化亮度），不急于二值化。
- **sync 鲁棒对齐**：用软相关的滑动匹配找 sync，而非硬峰谷；多个 sync 联合最小二乘估计位周期，消除单 sync 错。
- **软判决 BCH**：把软信息喂给 BCH 译码（如基于可靠性的 Chase 算法或软输入 Berlekamp），纠错能力比硬判决提升 2~3dB（约多纠 1~2 个错）。

> 投入产出比：⭐⭐⭐（边际场景救场，在追踪已稳后收益最明显）

---

### 阶段7 BCH：放宽纠错上限 + 双重校验

现状：63bit 实际 `t=5` 却只接受 `err≤3`，偏保守。这是为防误纠。

**最优：**
- 接受 `err≤5`（用满纠错力），但加**多重校验**防误纠：
  1. 纠错后 re-encode 比对（现状已有，保留）。
  2. 校验预设零位（`PRESET_*_ZERO_BITS`，现状 112bit 已有，63bit 也可加）。
  3. 63bit 与 112bit 结果交叉验证（若两种模式都解码，结果应一致）。
- 解锁后，处于"刚好超硬判决阈值"的边缘帧能被救回。

> 投入产出比：⭐⭐

## 五、推荐的目标架构：从"串行贪心链"到"模型驱动 + 全局约束"

```
                ┌─────────────────────────────────────────┐
                │  盾牌几何模型 (4角/2短2长/对称/周长先验)  │  ← 贯穿全程的全局约束
                └─────────────────────────────────────────┘
   定位(1D扫描,多候选)                                          │
        │ 初始边2点 + frame_size + 朝向                         │
        ▼                                                      │
   外框获取: 法向匹配滤波跟线(替代质心)  ◄──────────────────┘ 校验连续性
        │                                                      │
        ▼                                                      │
   角点检测: 分段延伸 + 曲率突变 + 弧长/对称先验补全  ◄────────┘ 全局约束补缺
        │ 4角(亚像素)                                           │
        ▼                                                      │
   每边独立几何模型 + 模块中心定位采样(无累积误差)               │
        │ 4条波形(软值)                                         │
        ▼                                                      │
   软sync对齐 + 软判决                                          │
        │ 软bit                                                 │
        ▼                                                      │
   软判决BCH(放宽t + 多重校验)  ◄─────────────────────────────┘ 63/112交叉验证
        │
        ▼
   ISLI 编码
```

### 三条结构性改变（这是"最优"的本质，而非调参）

1. **容错结构**：从"任意一点失败→全盘报废"改为"局部失败→用全局先验补全"。盾牌的 4 角 / 对称 / 周长是免费的高价值先验，现状完全没用。
2. **稳健核**：质心跟线 → 法向匹配滤波。这一项预计独立把成功率从 ~30% 拉到 ~85%+（消灭 70% 的追踪失败）。
3. **信息保真**：硬判决全程 → 软判决全程。每个模块的置信度一路传到 BCH，边缘帧救回率显著提升。

## 六、落地优先级（按 ROI 排序）

| 优先级 | 改动 | 预期成功率提升 | 工作量 | 风险 |
|--------|------|--------------|--------|------|
| **P0** | 阶段2：法向匹配滤波替换质心跟线 | +50~55% | 中 | 低（可A/B对比） |
| **P0** | 阶段3：分段延伸找角 + 对称/弧长先验补全 | +10~15% | 中 | 低 |
| **P1** | 阶段5：模块中心定位采样（去累积误差） | +3~5% | 中 | 中 |
| **P1** | 阶段6+7：软判决 + 放宽BCH + 双重校验 | +3~5% | 中高 | 中 |
| **P2** | 阶段1：定位多候选 + frame_size 交叉估计 | +1~2% | 低 | 低 |

**第一步建议**：只做 P0 的"法向匹配滤波跟线"，用现有 101 张测试图 A/B 验证（PC 测试程序已就绪，可一键跑全量）。这是风险最低、收益最大的一步——若追踪成功率从 30% 升到 85%，整盘盘活，再决定是否上 P1/P2。

## 七、附：当前设计中值得保留的好东西

不是全盘否定——以下设计应保留：
- **BSPatternMatch 的宽度比例匹配**：尺度不变，鲁棒，定位成功率 100%。
- **BCH 纠错后 re-encode 校验**：防误纠，安全。
- **三次曲线逐边拟合**：对光滑盾牌边是合理模型（只要追踪点准）。
- **内存池 + 各阶段日志**：已优化到位，便于 A/B 度量。
