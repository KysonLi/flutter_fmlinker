## 1. 系统架构总览

条码生成分为**三个独立层级**：

```
┌──────────────────────────────────────────────────────────┐
│ Layer 1: BCH Error Correction (bch.cpp)                  │
│   63-bit payload → BCH(127, 63, 7) → 112-bit codeword   │
│   GF(2^7), m=7, t=7, 可纠错 ≤7 bit                        │
├──────────────────────────────────────────────────────────┤
│ Layer 2: Sync Interleaving (ISLICodeLineEmbedder.cpp)     │
│   112-bit codeword → 10 sync patterns + 8 data blocks    │
│   → 142-bit linear stream                                │
├──────────────────────────────────────────────────────────┤
│ Layer 3: Visual Rendering (MainWindow.cpp)                │
│   142-bit stream → 2-line barcode image                  │
│   Bit=1→black square, Bit=0→white square + anti-fake     │
└──────────────────────────────────────────────────────────┘
```

## 2. BCH 纠错编码层

### 2.1 BCH 参数选择

```cpp
// ISLICodeLineEmbedder.cpp:122
bch_control* bch_ctrl = init_bch(7, 7, 0);
```

| 参数 | 值 | 说明 |
|------|-----|------|
| `m` | 7 | Galois 域 GF(2^7) = GF(128)，最大码字长 2^7-1 = **127 bits** |
| `t` | 7 | 最大可纠正 **7 bit** 错误 |
| `prim_poly` | 0 (默认) | 自动选择 `prim_poly_tab[7-5]` = **`0x83`** (二进制 `10000011`) |
| 本原多项式 | `x^7 + x + 1` | `0x83` 对应多项式: bit7=1·x^7, bit1=1·x, bit0=1·1 |
| ECC 位数 (`ecc_bits`) | **49 bits** | 由生成多项式自动计算，度数为 49 |
| 数据位数 | **63 bits** (有效载荷) | 总码字格 127 bits, 码率 = 63/127 ≈ 0.496 |

> **为什么 m=7?** GF(2^7) 提供 127 位码字空间。112 位编码数据 (63+49) 需要 ≤ 127 位，所以 7 是最紧凑的选择。

### 2.2 Payload 入参约束

```cpp
// ISLICodeLineEmbedder.cpp:15
if (payload > 0x5555555555555555)
    return EET_INVALID_ISLI_CODE;
```

- **最大合法值**: `0x5555555555555555` = `6,148,914,691,236,517,205`（十进制）
- **位数**: 63 位有效位，但最高位受此限值约束
- **含义**: 保证 BCH 编码器的 80 位数据帧中，高 17 位和低若干位均为 0

### 2.3 编码数据帧布局 (80 bits → 10 bytes)

```
字节布局 (BYTE0~BYTE9, 每个 LSB-first bit 序):
┌──────────┬──────────┬─────────────────────────────────────────┐
│  BYTE0   │  BYTE1   │  BYTE2 ~ BYTE9                          │
│bit[0..7] │bit[0..7] │bit[0..63]                               │
├────┴─────┴────┴─────┴─────────────────────────────────────────┤
│ xxxx 0000 0000 0000 | 0000 0000 | vvvv vvvv vvvv vv00  ←63bit→│
│ ←16bit→ + ←1bit→    | ←8bit→                    ←54bit→       │
│ 全零                  | 全零          payload (k=0..62)        │
└────────────────────────────────────────────────────────────────┘

总 bit 序 (i = 0..79):
  i = 0..16  → 固定为 0 (高17位)
  i = 17..79 → payload 的 bit[k], k = i - 17
```

**代码实现**:
```cpp
// ISLICodeLineEmbedder.cpp:125-132
for (i = 0, k = 0; i < 80; i++) {
    if (i < 17)           // 跳过前 17 位
        continue;
    if (payload & ((long long)1 << k))   // payload 的 bit(k)
        data[i / 8] |= 1 << (i & 7);     // 写入 data[] 对应 bit 位
    k++;
}
```

> **注意**: data[] 的 bit 序是 **LSB-first**（b0 为字节最低位）。即 BYTE0.b0 对应 i=0，BYTE0.b7 对应 i=7。

### 2.4 ECC 校验位生成

```cpp
encode_bch(bch_ctrl, data, 10, ecc);
// data = 10 字节 (80 bits)
// ecc  = 7 字节 (56 bits), 其中有效 49 bits
```

ECC 输出布局:
```
ecc[7 bytes]:
┌─────────┬─────────┬─────────┬─────────┬─────────┬─────────┬─────────┐
│  ecc[0] │  ecc[1] │  ecc[2] │  ecc[3] │  ecc[4] │  ecc[5] │  ecc[6] │
│ 8 bits  │ 8 bits  │ 8 bits  │ 8 bits  │ 8 bits  │ 8 bits  │ 8 bits  │
├─────────┴─────────┴─────────┴─────────┴─────────┴─────────┴────┬────┤
│  Effective: 49 bits (bit 0~48)              │ bits 49~55 无效  │
└────────────────────────────────────────────────────────────────┘
```

### 2.5 组装 112-bit BCH 编码位 (bch_encoded_bits[14])

```
bch_encoded_bits[14 bytes] = 112 bits:

┌────────────────────────────────────┬──────────────────────────────────────────┐
│      63-bit payload data            │         49-bit ECC parity               │
│   (k=0..62 from data bytes)        │   (k=63..111 from ecc bytes,            │
│                                    │    跳过 ecc bit 48~54)                    │
└────────────────────────────────────┴──────────────────────────────────────────┘

数据段 (bits 0~62):
  for i=0..79, skip i<17
    bch_encoded_bits[k] = data[i];  k++

ECC段 (bits 63~111):
  for i=0..55 (ecc 7×8=56),
    skip i=48..54 → 7 bits excluded
    bch_encoded_bits[k] = ecc[i];  k++
```

**代码**:
```cpp
// 组装数据部分
for (i = 0, k = 0; i < 80; i++) {
    if (i < 17) continue;
    if (data[i / 8] & (1 << (i & 7)))
        bch_encoded_bits[k / 8] |= 1 << (k & 7);
    k++;
}
// 组装 ECC 部分 (跳过 bit 48~54 共7位)
for (i = 0; i < 56; i++) {
    if (i >= 48 && i < 55) continue;
    if (ecc[i / 8] & (1 << (i & 7)))
        bch_encoded_bits[k / 8] |= 1 << (k & 7);
    k++;
}
// 最终 k = 63 + 49 = 112
```

## 3. 同步码与比特交织层

### 3.1 常量定义

```cpp
#define bitcounts_perpices_data   14   // 每个数据块包含 14 bit
#define bitcounts_perpices_check  3    // 每个同步码 3 bit
#define counts_pices              8    // 共 8 个数据块
#define counts_total_data         112  // 总数据位 = 8 × 14 = 112
#define counts_total              142  // 总输出位 = 112 + 3×10 = 142
```

### 3.2 同步码类型

同步码用于扫描时 **检测条码段落边界和方向**。两种类型：

| 类型 | 模式 | 命名 | 位序列 |
|------|------|------|--------|
| 正常 | `101` | NORMAL | 1 (深), 0 (浅), 1 (深) |
| 反转 | `010` | INVERTED | 0 (浅), 1 (深), 0 (浅) |

> 反转模式用于标记条码的**中间位置**和**终点位置**，允许扫描器在不依赖条码起点的情况下识别方向。

### 3.3 完整 142-bit 线性流布局

```
位置:    0   1   2   3   4   5   6  ... 15 16   17 18 19  20 ...   ..139 140 141
        ├─S1─┤├────── D1 (14 bits) ────┤├─S2─┤├────── D2 ────┤...├─S10┤
        │1│0│1│ b0 b1 b2 b3 ... b13 │1│0│1│ b14 ... b27 │...│0│1│0│
        └───┘└───────────────────────┘└───┘└─────────────┘   └───┘
```

**分块详细表:**

```
┌──────┬─────────────┬───────────────┬──────────────────────────────┐
│ 同步# │ 位索引(3bit) │ 同步值         │ 后续数据块                    │
├──────┼─────────────┼───────────────┼──────────────────────────────┤
│ S1   │   0..2      │  1 0 1 (正常)  │ D1: bch[ 0..13] → 位  3..16  │
│ S2   │  17..19     │  1 0 1 (正常)  │ D2: bch[14..27] → 位 20..33  │
│ S3   │  34..36     │  1 0 1 (正常)  │ D3: bch[28..41] → 位 37..50  │
│ S4   │  51..53     │  1 0 1 (正常)  │ D4: bch[42..55] → 位 54..67  │
│ S5   │  68..70     │  0 1 0 (反转)  │                              │
│ S6   │  71..73     │  0 1 0 (反转)  │ D5: bch[56..69] → 位 74..87  │ ★
│ S7   │  88..90     │  1 0 1 (正常)  │ D6: bch[70..83] → 位 91..104 │
│ S8   │ 105..107    │  1 0 1 (正常)  │ D7: bch[84..97] → 位108..121 │
│ S9   │ 122..124    │  1 0 1 (正常)  │ D8: bch[98..111]→ 位125..138 │
│ S10  │ 139..141    │  0 1 0 (反转)  │ (无后续数据)                   │
└──────┴─────────────┴───────────────┴──────────────────────────────┘
```

> ★ **关键异常**: S5 和 S6 是两个连续的同步码，中间**没有**数据块。这导致 D5 前面的跳跃量是 6 位（两个同步码），而其他数据块前面只跳 3 位。

### 3.4 数据位到输出位的映射算法

```cpp
pos = 0;
for (int i = 0; i < counts_total_data; i++)  // i = 0..111
{
    // 每 14 bit 插入一个同步码
    if (i % 14 == 0)
    {
        if (i / 14 == 4)  // 第5组数据: 前面有两个连续同步码
            pos += 6;     // 跳过 S5 + S6 (2×3=6 位)
        else
            pos += 3;     // 跳过 1 个同步码 (3 位)
    }
    // 将 bch_encoded_bits[i] 写入 t[pos]
    if (bch_encoded_bits[i / 8] & (1 << (i & 7)))
        t[pos] = 1;
    pos++;
}
```

**直观展示 `pos` 的变化轨迹**:

```
i=0, i/14=0 → pos+=3, pos=3
  i=0..13 → pos= 3..16  → D1 写入位置 3~16
i=14, i/14=1 → pos+=3, pos=20
  i=14..27 → pos=20..33 → D2 写入位置 20~33
i=28, i/14=2 → pos+=3, pos=37
  i=28..41 → pos=37..50 → D3 写入位置 37~50
i=42, i/14=3 → pos+=3, pos=54
  i=42..55 → pos=54..67 → D4 写入位置 54~67
i=56, i/14=4 → pos+=6, pos=74  ★ 跳6位而非3位
  i=56..69 → pos=74..87 → D5 写入位置 74~87
i=70, i/14=5 → pos+=3, pos=91
  i=70..83 → pos=91..104→ D6 写入位置 91~104
i=84, i/14=6 → pos+=3, pos=108
  i=84..97 → pos=108..121→ D7 写入位置 108~121
i=98, i/14=7 → pos+=3, pos=125
  i=98..111→ pos=125..138→ D8 写入位置 125~138
            pos最终=138, 然后 S10 占据 139~141
```

### 3.6 同步码功能说明

| 同步码 | 模式 | 功能解读 |
|--------|------|---------|
| S1 | 101 | **条码起点** — 正常相位标记开始 |
| S2~S4 | 101 | **前段分隔** — 标记数据块 D2~D4 的开始 |
| S5+S6 | 010+010 | **中点标记** — 两个连续的反向同步码 = 条码正中（第71位处），同时也是两行之间的分界 |
| S7~S9 | 101 | **后段分隔** — 标记数据块 D6~D8 的开始 |
| S10 | 010 | **条码终点** — 反转相位标记结束 |

> **设计意图**: 正常(101)和反转(010)的交替使用 → 扫描器可以通过检测反转段来判断条码的中间和末尾位置，从而在任意方向扫描时都能正确解析比特流。

## 4. 可视化渲染层

### 4.1 两行布局

142-bit 线性流被分割成 **两行**，每行 **71 位**:

```
Line 0: bits[  0.. 70]  → 位置: x = 0..70*bit_expand, y = 0
Line 1: bits[ 71..141]  → 位置: x = 0..70*bit_expand, y = bit_expand * 2
```

分割点恰好位于 S6(010) 之后、D5 之前 — 即两个反转同步码作为"折行标记"。

### 4.2 黑白块的像素图案

#### 黑块 (bit=1)
- 纯色 `bit_expand × bit_expand` 黑色矩形

#### 白块 (bit=0, `type=2` 防伪模式)
- 白色底，内含黑色防伪纹理
- **纹理规则**（对每个像素 `(j, l)` 坐标）:

```cpp
// MainWindow.cpp:170-177, type=2
if ((l / piece_expand) % 2 == 0 || (l / piece_expand) % 3 == 0)
{
    whiteimage.setPixelColor(j, l, Qt::black);
}
```

效果 (示意 `piece_expand=2`, `bit_expand=30`, 15×15 的子单元格):

```
黑-白-黑-白-黑-白-黑-白-黑-...
黑-黑-黑-黑-黑-黑-黑-黑-黑-...
黑-白-黑-白-黑-白-黑-白-黑-...
黑-黑-白-黑-黑-白-黑-黑-白-...
...
```

**纹理解读**:
- **纵向每隔 piece_expand 像素**（`(l/piece_expand)%2==0`）→ 黑色横纹
- **纵向每隔 piece_expand 像素的 3 倍频处**（`(l/piece_expand)%3==0`）→ 叠加黑色密纹
- 综合效果 = 棋盘格 + 防伪网纹，难以通过简单复印复制

### 4.3 其他图案类型（已存在但未使用）

代码中还定义了 `type=0` 和 `type=1` 的模式，但当前使用 `type=2`：

| type | 图案 | 说明 |
|------|------|------|
| 0 | 棋盘格 + 四周边框 | 4px 边框 + checkerboard (j/l 异或) |
| 1 | 条纹 | 每 piece_expand 行为一条黑带 |
| **2** ✅ | **网纹+横纹** | 当前使用，兼具美观和防伪 |

### 4.4 打印尺寸参数

```cpp
int piece_expand = 2;     // 基础像素缩放因子
int piece_count = 15;     // (用于DPI计算)
int bit_expand = piece_count * piece_expand;  // = 30 pixel/bit
// 条码长度 = bit_expand * 71 / 2400 * 25.4 ≈ 2.25 cm (at 2400 DPI)
int w = bit_expand * 71;  // = 30 × 71 = 2130 px (≈ 22.5mm at 2400dpi)
int h = bit_expand * 3;   // = 30 × 3 = 90 px (两行各60px，间距30px)
```

| bit_expand | 每bit尺寸 | 71位行长 | 适用场景 |
|-----------|----------|---------|---------|
| 30 | 30×30px | ~22.5mm | 大尺寸打印 (type=2 白块图案) |
| 8  | 8×8px   | ~24.0mm | 标准打印 (Print 函数, 4×2 棋盘格) |
| 4  | 4×4px   | ~12.0mm | 小型打印 (Print 函数) |
| 6  | 6×6px   | ~18.0mm | 最小打印 (Print 函数, piece_expand=1) |

## 5. 完整数据流

### 5.1 从 Payload 到图像 — 逐步示例

假设 `payload = 1610900005` (十进制) = `0x60010025` (十六进制，仅低 63 位有效):

```
Step 1: Payload 校验
  payload = 0x60010025
  0x60010025 ≤ 0x5555555555555555?  → ✓ OK

Step 2: BCH 编码 (BCHEncode63)
  data[10] = 80-bit 帧, 前17位=0, 后63位=payload
  encode_bch(data, 10, ecc[7])
  → ecc 包含 49-bit 有效校验位

Step 3: 组装 112 位编码数据 (bch_encoded_bits[14])
  bits[0..62]  = payload 的 63 位
  bits[63..111] = ecc 的 49 位 (跳过 bit48~54)

Step 4: 同步码交织 (DoEmbedding)
  142-bit 流: [101][D1:14bit][101][D2:14bit]...[010]
  每14个数据位前插入3位同步码，第5组前插入6位

Step 5: 两行分割
  Line 0: bits[0..70]
  Line 1: bits[71..141]

Step 6: 像素渲染
  对于每个 bit:
    bit==1 → 黑方块 (bit_expand × bit_expand)
    bit==0 → 白方块 + 防伪纹理 (bit_expand × bit_expand)

Step 7: 保存/打印
  mImage.save("F:\{payload}.png")  // 自动保存
```
