泛媒关联 App · 业务运营流程全景图

扫一扫纸书上的 ISLI 链码 → 解析并播放关联的全媒体资源 → 付费解锁优质内容 → 缓存离线复看与用户沉淀
内容运营 扫码关联 付费转化 离线缓存 用户留存 Android / iOS / HarmonyOS

1业务角色与价值链 谁提供内容、谁提供服务、谁消费内容

内容供给侧 · 出版机构 / 出版者
  • 申报 MPR 出版物（Goods）并上传数字资源（Source）
  • 为纸书申请 ISLI 链码 / 标志码，随印刷物一并发行
  • 配置资源定价策略与促销优惠，投放运营位
  • 后续维护：内容更新记录、上架 / 下架 / 删除
→
平台侧 · 泛媒关联云平台
  • 码解析服务：/target-goods/app/v1/source/scan 按码取关联资源
  • 内容库：出版物库、出版者库、资源文件与分发（图片 byte 流 / 音视频 / HTML / 3D OBJ）
  • 交易：定价策略、减免优惠、订单与微信支付
  • 账号：短信 / 密码 / 微信 / 南方云教育平台对接、多设备管理
  • 运营数据：扫码量、阅读数、点赞数、购买记录
→
需求侧 · 阅读用户（App）
  • 扫描纸书链码，直达配套图文 / 音视频 / 3D 内容
  • 浏览出版物、发现推荐位找书
  • 单本购买 / 整书打包购买解锁优质资源
  • 缓存离线复看、点赞、查看历史与购买记录

3用户获取内容的 4 大入口 所有入口最终汇聚到统一资源入口 ResourceEntry.openFromCode()

A · 扫码直达（核心入口）
  • 底部中央凸起按钮 → 全屏扫码页
  • 链码（线码）／标志码（图标码）模式切换
  • 相册识码、手动输入链码（10~20 位数字）
  • native C++ 解码（BCH 纠错 + 波形采样）
/scan
B · 出版页找书
  • 出版物 / 出版者两个子 Tab，卡片或列表切换
  • 关键词搜索（同时搜书与出版者，存历史词）
  • 出版物详情：链码行 → 资源清单
/publish → /publication-detail
C · 发现页运营位
  • 轮播 Banner（可跳站内书或外链）
  • 今日推荐、热门关注、点赞最多榜单
  • 点击直达出版物详情
/discover → /publication-detail
D · 关联历史复访
  • 扫码历史卡片流（带上下架 / 已删除角标）
  • 关联出版物管理：批量删除、分页加载
  • 未登录时引导登录或去出版页浏览
/history → /link-management
统一资源入口
ResourceEntry.openFromCode()
① 先 refreshToken() 回灌登录态 → ② 按链码拉取关联资源 /source/scan → ③ 依据返回结果分流： 需要购买进购买页、多资源进资源列表、单资源直进播放页；无关联资源则提示「未获取到关联资源」。
▼按返回结果分流
needPurchase == true
需付费解锁
  • 跳转购买页，展示资源信息与价格
  • 无资源预览，先买后看
资源数 大于 1
资源列表页
  • 分页加载，滚到底自动加载更多
  • 可切换链码、扫码、查看源详情
资源数 等于 1
直接进入播放页
  • 左右滑动切换同一码下的多个资源
  • 顶部点赞、底部更多（购买 / 列表 / 源详情）
标志码 / ISBN / ISSN
ISLI 版权信息页
  • 展示该码的登记与版权信息
  • 链码类走资源解析链路

4资源消费：按类型分发 + 离线优先

资源类型分支
  • 文本：在线正文 / SelectableText
  • 图片：网络图（byte 流）或本地文件
  • 音频 / 视频：统一播放器内核，HLS 分段支持
  • 网页：内置 WebView 打开 HTML 应用
  • 3D：OBJ 模型页，可旋转缩放
  • 付费未解锁 → 锁定态「购买后即可查看」
离线缓存（运营留存的关键）
  • 播放页一键缓存，串行下载队列 + 进度
  • WiFi 直下；移动网络弹确认（24 小时内免重复询问）
  • 文件按资源 ID 全局复用，元数据按账号隔离
  • 我的缓存：已缓存 / 任务列表，可删可重试
离线播放兜底
  • 无网络时自动载入本地已缓存资源并提示
  • 无缓存则提示「当前离线且无本地缓存」
  • 缓存详情页点条目直接本地播放
  • 网页类型资源不提供缓存

5付费转化链路 免费内容直通，付费内容按策略售卖

1
命中付费资源
解析结果显示需购买
或播放页点击「购买后解锁」
▶
2
购买页组装订单
资源信息 + 价格；单个源 / 整书 两种规格
整书统一价策略下仅支持整书
▶
3
优惠与身份校验
拉取整书减免价；非免费策略需登录
未登录 → 引导登录后继续
▶
4
支付
CHAIN_ALL_FREE：0 元直接「获取成功」
付费：微信下单支付（接入中）
支付成功 = errCode 0
▶
5
解锁并回流
返回播放页自动刷新解锁状态
订单写入「购买记录」，可再次进入资源

6用户沉淀与留存运营

账号体系
  • 短信验证码 / 账号密码 / 微信 / 南方云教育
  • 未绑定手机号强制补绑
  • 账号安全、设备管理、注销账号
互动与收藏
  • 播放页点赞 / 取消点赞，驱动「点赞最多」榜单
  • 我的点赞：集中回访喜欢的内容
  • 出版物详情展示阅读数与关联点赞数
资产与复访
  • 购买记录：按整书 / 单源分别回到对应资源
  • 我的缓存：离线内容随时复看
  • 关联历史：扫码记录一键重温
服务与反馈
  • 常见问题、扫码帮助、链码科普页
  • 意见反馈直达运营团队
  • 关于我们 / 协议与隐私政策（WebView）
