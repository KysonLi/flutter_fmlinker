Q1：

What is MPR publication?

A1：

The MPR (Multimedia Print Reader) publication is a publication based on unique link codes, which particularly takes matrix MPR two-dimensional codes as machine-readable symbols, to integrate and accurately link various publishing carriers and representations, and develop a Multimedia digital publication based on paper printing.
MPR publications are composed of three basic elements: MPR books and newspapers, MPR digital media documents, and MPR codes which enables accurate links between them.

Q2：

What is MPR publication(multi-media version)?

A2：

The MPR publications that printed with "chain code" is the full media version of MPR publication, the MPR (logo) is printed on the cover 。

Q3：

Can the publication with MPR Logo on the cover scan the chain code?

A3：

Only MPR publications (full media version) support scan code.
MPR publications fall into two categories:
(1) MPR publications (full media version) printed is the chain code, its appearance is similar to double underscore, with mobile phone login device scan chain code can obtain the paper media related graphics, audio, video, 3D, H5 and other formats of digital content.
(2) MPR publications (click and read version) print is nearly invisible matrix two-dimensional code, through the link MPR reader click on the MPR code on the publication, play the audio or video multimedia digital content associated with the identified content.

Q4：

Why can "link code directory" only view the first two resources, but not all resources?

A4：

Because the chain code resource is related to the printed MPR publication content, the purpose is to read the paper and electricity related, and use the scanning function to view the chain code resource. Depending on the publisher Settings, some publications can play the resource examples associated with the first two link codes.

Q5：

Where can I buy MPR publications?

A5：

Please purchase paper books printed with chain code through third-party platforms, such as amazon, jingdong, dangdang, or offline bookstores. Please buy newspapers at the newsstand.
To purchase MPR publications (full media version), please first identify the MPR Logo on the book cover ,and confirm that the code printed in the book is "chain code".
MPR publications that support chain code (full media version) can be viewed in the list of APP publications.
